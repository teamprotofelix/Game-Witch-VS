# 마녀 아라 · 달빛 사냥 v2.2 CINEMATIC

기존 **v2.0 HD**를 기반으로 리얼 판타지 이벤트 컷과 액션 스프라이트를 보강한 정적 HTML/JS 게임입니다. 빌드 도구·백엔드·CDN·API 키 없이 동작합니다.

## v2.2 주요 변경

- **고화질 마녀 아라 초상**: 사용자 레퍼런스 사진의 분위기를 기준으로 새로 제작한 1122×1402 실사풍 WebP 아트. 기존 직접 잘라낸 사진은 화면에서 쓰지 않음.
- **이벤트 서비스컷 4종**: 지역 진입/각성, 레벨업 축복, 보스·궁극 마법, 승리 엔딩. 이미지 1672px 가로, WebP 최적화. 이벤트 스킵 가능. 일시정지 → 서비스컷 켜기/끄기 가능.
- **메인 메뉴 내 마법화보 갤러리**: 5장의 새 화보 보기.
- **스프라이트 보강**: 마녀의 추가 시전 포즈 8프레임, 별여우 신규 8프레임, 개별 5종×6프레임의 투명 마법진 WebP, 기존 12프레임 주인공 이동·8종×4프레임 몬스터 유지.
- **게임성**: 연속 12콤보 단위로 달빛 피버, 마력 회복·보너스 점수·특수 마법진. 기존 마법 연성·아이템 수집·별의 축복·보스의 예고 공격·대시 회피 등 뱀서류 메커니즘 유지.
- **PWA**: 모든 신규 아트를 오프라인 캐시로 구성. 이전 버전의 오래된 리소스 캐시를 정리하도록 캐시명을 갱신하고 캐시 조회 범위를 새 버전으로 한정.

## 게임 실행

GitHub 저장소 루트에 ZIP **내용물**을 업로드하세요 (`index.html`, `game.js`, `assets/`, `icons/` 등 모두 같은 최상위 경로). GitHub Pages에서 `main /(root)`로 배포합니다. 현재 `CNAME`은 기존 URL을 보존합니다. 호스팅 서버에 사전 설치 프로그램은 필요 없습니다.

- PC: 방향키/WASD 이동, Space 대시, 1·2·3 마법, C 마법 연성, Esc 일시정지. 마우스 드래그 이동 가능.
- Android: 왼쪽 조이스틱 이동, 오른쪽 대시/마법 버튼. 레벨업 시 축복 카드 선택.
- 재료 수집 → 상단 연성 버튼, 레벨업 → 축복 카드 선택. 3개 제단 정화 시 회복 및 점수. 보스가 나타나면 빨간 경고 원에서 벗어나세요.
- 서비스컷이 나타나면 **계속하기/화면 탭** 또는 Enter·Space·Esc로 넘길 수 있습니다. 각 이벤트에 따라 자동으로 사라집니다.

## 개인정보·의존성

외부 분석 코드, 광고 SDK, 외부 폰트, 개인정보 전송 및 API 요청이 없습니다. 로컬에 게임 진행·설정이 저장됩니다. 원본 레퍼런스 사진 파일은 이 배포 ZIP에 넣지 않았습니다. 사용자 얼굴에서 파생된 이미지 및 생성 일러스트는 게임 아트로 포함됩니다.

## 확인 범위

Chromium 헤드리스 브라우저의 HTML/CSS/JS 인메모리 구동에서 데스크톱 1365×800과 모바일 390×844 크기의 새 게임 시작, 지역 이벤트 스킵, 연성·마법, 레벨업 일러스트, 보스 출현 및 지역 전환, 승리, 캐시 참조 등 검사를 진행했습니다. HTTP/HTTPS 접속, 실제 Android/iOS 기기, GitHub Pages 서비스 워커 설치 및 현장 터치 성능은 이 환경에서 별도로 확인하지 못했습니다.

## 파일 구성

- `game.js` : 단일 Canvas 게임 엔진 / 이벤트 제어, 입력, 마법 및 레벨 성장
- `index.html`, `style.css` : 게임 HUD, 스토리 이벤트, 마법화보 갤러리
- `assets/events/` : 실사풍 마법 이벤트 컷 4종
- `assets/portraits/ara_cinematic.webp` : 신규 메인 초상
- `assets/hero/ara_cast_*.webp`, `fox_*.webp` : 신규 스프라이트
- `assets/vfx/*` : 개별 프레임 마법진
- `sw.js`, `manifest.webmanifest`, `icons/` : PWA 오프라인 설치 파일
- `screenshots/` : 검토용 브라우저 화면 캡처
